## Body

```text
Hi HN,

I am building DaoRoute, a non-custodial MCP server for AI agents and DeFi automation builders evaluating stablecoin allocation routes.

The idea is to package a DeFi allocation decision as structured evidence an agent can consume:

- market snapshot
- one-pool evidence
- protocol security status
- allocation decision packet
- execution metadata
- optional signed attestation

DaoRoute is not a wallet, trading bot, or custody layer. It does not sign transactions, broadcast transactions, guarantee returns, or provide investment advice. The current version is a free controlled pilot for feedback from agent and Web3 builders.

The public repo contains the pilot pack, integration guides, redacted examples, marketplace metadata, and API key policy:
https://github.com/DAltieri86/DAORoute-mcp

Landing:
https://www.daoroute.com/

I would appreciate feedback on:

1. Whether the MCP response shape is useful for agent workflows.
2. Which fields are missing for policy review.
3. Whether the non-custodial boundaries are clear.
4. Which integrations should be prioritized next.
```
